# ADZOO — Инстинкт рекламы

Десктопный анимированный прототип. Откройте `index.html` или загрузите содержимое папки в корень публичного репозитория GitHub Pages.

- `index.html` — четыре секции, обычные `div`, `img`, текст.
- `images` — отдельные рисунки. SVG — готовые векторные картинки. `native-pattern.webp` — готовая прозрачная анимация узора хамелеона; её статичный кадр используется при паузе.
- `styles/reset.css` — сброс отступов.
- `styles/layout.css` — композиция и первый экран.
- `styles/animation.css` — движение через `@keyframes`, `transform`, `opacity`.

Для изменения положения рисунка меняйте `left` и `top` в HTML, для размера — `width` и `height`. Скорость — число секунд в `animation`. Отрицательный `animation-delay` задаёт разную фазу движения. Группы `div` вращаются вокруг `transform-origin`.

Обычная галочка «Пауза анимации» управляет CSS через `:checked` и `~` (селектор следующих элементов). На паузе узор хамелеона заменяется неподвижным кадром. Системное уменьшение движения также учитывается. Это два небольших вспомогательных правила.

JavaScript, библиотеки, встроенные SVG, мобильный макет отсутствуют. Сохранена десктопная композиция; сложная маска превращена в готовое изображение.
